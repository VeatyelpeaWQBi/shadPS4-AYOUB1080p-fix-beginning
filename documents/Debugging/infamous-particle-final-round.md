# 车祸场景最后一轮对照与回滚（2026-10-13）

最后一轮没有取得明显、可重复的收益，已按用户要求回滚追加调优。
普通启动恢复原进程 CPU 调度范围、无边框全屏、512 KiB 回读窗口、200 µs
录制等待和 256 条录制批量。保留港版适配、开场修复、输入功能、持久化缓存与
预热、已验证的剧情选择优化，以及防止火焰周期性重启的访问保护修正。

缓冲候选仅把图形缓冲访问的同步来源缩减到光栅化前着色器及片元着色器阶段，
没有删除读写依赖、减少粒子、修改着色器运算或放宽 CPU 回读。候选无明显收益，
已撤回。全屏试验专用启动入口也已移除，普通脚本保持原显示设置。

原/候选同步对照的其他程序同适配器 3D 活动均值约 0.26%–0.44%；全屏/
回滚对照也处于低干扰状态。Windows 引擎活动不等同于 Vulkan 时间戳。
全屏与无边框的显示输出均为 3840×2160；游戏内部渲染仍为 1080p、PS4 基础模式。
这不是 PS4 Pro 原生 4K 性能验证。不同启动之间存在小幅漂移，不将其当作优化效果。

## 回滚范围与验证

- 取消普通港版配置中的 `cpu_affinity=auto-p-single` 默认策略，恢复 `cpu_affinity=0`。
  提交前已移除该自动选核及 CPU 分组的实验实现；历史约 3.3% 的小幅改善不作为保留理由。
- 新增同步候选没有留在渲染代码中；此前失败的渲染候选没有接入普通启动。
  不删除已积累的有效着色器/管线缓存，不回退已验证的功能修复。
- 回滚版采样 8 张画面，跨度约 12 秒。左右火焰区域均持续存在，未复现集体消失/
  重启；尺寸为 1920×1080，压缩逐像素校验通过。此为该存档场景的有限验证。
- 最终 Release 构建成功，现有 7 项检查全部通过。最终 EXE SHA256：
  `34463FEBA396DE9E73D21785BC9E48D0E40B5DE74906212292BAA3C12ED70D29`。
- 普通/诊断 1080p、4K BAT 继续指向 `Build/x64-Clang-Release/shadps4.exe`。
  QtLauncher 中另行复制的 EXE 未覆盖；本轮未测试 PS4 Pro 4K 或完整章节。
- 测试仅挂载各自的隔离 home。原活动存档未挂载，车祸/选择场景命名备份校验
  保持不变；没有恢复旧进度备份，没有修改游戏本体，没有提交或上传 Git。

保留的旧正确基线 SHA256 为
`3A74A1808D65C0408F11324E6F1929F28A08A558CF7C8449D850ED4FDEB4A4F7`。
worker 的 baseline 入口已改为这一版本并校验指纹，避免再次使用曾导致
火焰周期性重启的错误基线。最终状态见 `Build/particle-benchmark/final-round-results.json`。

本轮可验证的方案没有明显收益，不表示所有深层 GPU 优化都不可能。
按用户要求结束本轮推进，不再继续追加试验。
